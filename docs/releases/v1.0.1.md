# EchoReplay v1.0.1 — Windows 安裝版

現在可以直接下載安裝，不需要原始碼、編輯器或 .NET。

## 下載哪個檔案？

- **`EchoReplay-Setup-x64.exe`（建議）**：下載後雙擊，依畫面完成安裝，從開始功能表開啟 EchoReplay。
- **`EchoReplay-portable-win-x64.zip`**：免安裝版，解壓縮整個資料夾後執行 `EchoReplay.exe`。
- `SHA256SUMS.txt`：以上兩份下載檔案的 SHA-256 校驗值。

GitHub 自動附上的 **Source code** 是原始碼，一般使用者不需要下載。

## 安裝行為

- Windows x64；最低 Windows 10 1809。Windows 10／11 的不同硬體情境仍需實際驗證。
- 安裝到目前使用者的 `%LOCALAPPDATA%\Programs\EchoReplay`，不需要管理員權限。
- 建立開始功能表捷徑，可選擇桌面捷徑。
- 可從 Windows「已安裝的應用程式」解除安裝；錄音與設定會保留。
- 啟動後預設開始錄音；開機自動執行預設關閉，可在工具設定內啟用。
- 更新或移除前，請先保存音訊，再從系統匣結束正在執行的 EchoReplay。

## 快速使用

1. 在「設定」選擇電腦播放裝置與麥克風，確認音量條有反應。
2. `Ctrl + Alt + F9` 儲存最近音訊，預設保留 5 分鐘。
3. `Ctrl + Alt + F10` 顯示／隱藏介面。關閉視窗後仍會背景錄音。

## 本版變更與限制

- 新增安裝程式、免安裝 ZIP、檔案校驗值及自動發佈流程。
- 執行中阻擋更新／移除，避免意外結束尚未儲存的錄音。
- 錄音功能與 1.0.0 相同；麥克風實機收音、雙來源同步與長時間運作仍待更多驗證。
- 安裝程式及 EXE 目前沒有程式碼簽章，Windows 可能顯示不明發行者或 SmartScreen 提示。請確認下載來源是 `cacich/EchoReplay` 的 GitHub Release。
- 麥克風直接從 Windows 擷取，Discord 靜音與按鍵發話不會控制這份錄音。
