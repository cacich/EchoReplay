# EchoReplay 1.1.0：直接剪輯錄音並輸出 MP3

下載 **EchoReplay-Setup-x64.exe** 安裝，或使用 **EchoReplay-portable-win-x64.zip** 免安裝版。升級前先從系統匣結束舊版；既有錄音與設定會保留。

## 新功能

- 音檔庫支援搜尋、匯入 WAV／MP3 副本、改名及刪除。
- 波形拖曳選取、滾輪縮放、精確秒數，以及最後 5／10／15／30 秒快捷選取。
- 裁切、多段刪除並接合、區間靜音、復原／重做。
- 內建播放、暫停、循環試聽，分軌音量與淡入淡出。
- 保存編輯進度，稍後繼續；原始音訊保持完整。
- 直接輸出 MP3 192／320 kbps 或 WAV，預設存入獨立的 Exports 資料夾。
- 原始錄音、分軌及進度可一起移至 Windows 資源回收筒，獨立成品保留。

## 使用方式

儲存最近音訊 → 剪輯／試聽最新錄音 → 選最後幾秒 → 保留選取範圍 → 匯出成品 → 在音檔庫刪除不需要的原始錄音。

## 已知範圍

- 剪輯器支援最長 15 分鐘、單聲道／立體聲音檔。
- 試聽聲音會被電腦錄音收錄；背景錄音不會自動暫停。
- Windows N／精簡系統的 MP3 功能可能需要媒體元件。WAV 可獨立使用。
- 此版尚未包含降噪、AI 人聲分離或 Discord／遊戲各自分軌。
- 程式尚未簽章；麥克風、Discord／遊戲情境及整晚錄音仍需更多實機驗證。
