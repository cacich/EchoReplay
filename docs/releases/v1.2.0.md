# EchoReplay 1.2.0：語音與遊戲分軌

下載 **EchoReplay-Setup-x64.exe** 安裝，或使用 **EchoReplay-portable-win-x64.zip**。升級前先保存片段，從系統匣結束舊版；錄音與設定會保留。

## 使用新功能

1. 開啟 Discord 與遊戲。
2. 設定 → 錄音模式 → **語音聊天／遊戲分軌**。
3. 語音選 Discord.exe，遊戲選實際遊戲 .exe，按套用。
4. 儲存後，在剪輯器關閉遊戲音軌並套用，就能匯出只有語音與麥克風的 MP3。

升級會保留原有指定裝置模式，需手動切換。也可選「所有程式」模式，錄製所有播放裝置的聲音並排除本次 EchoReplay 試聽。

## 功能

- 語音／遊戲／麥克風獨立音軌，所有剪輯維持共同時間軸。
- 記住程式名稱，關閉時等待，重啟後自動重連。
- 顯示來源 PID、連線狀態與音量；新模式排除 EchoReplay 播放聲音。
- 程式分軌固定保存來源 WAV，並保留混音、MP3／WAV 編輯匯出。
- 37 項測試及真實程序音訊分離、重連與排除試聽驗證。

## 支援範圍

程式模式需要 Windows 11 或 Windows build 20348 以上。一般 Windows 10 22H2 使用指定播放裝置模式；這個相容模式仍會錄到試聽。

分軌只適用新錄音，不能還原舊混音。同一 Discord 裡所有朋友仍在同一軌；同一瀏覽器的分頁也不會逐一分離。使用喇叭時，麥克風仍可能收到實體回音。

本機已用獨立合成音訊程序驗證 Windows 擷取與完整存檔流程；Discord／遊戲特定版本、反作弊環境、實體裝置切換與長時間錄音仍需目標硬體驗證。此版不包含 AI 人聲分離。
