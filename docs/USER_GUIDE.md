# 使用指南

Windows 10 / 11 的純音訊即時回放工具。持續保留最近 1、3、5 或 10 分鐘的電腦聲音和麥克風，事情發生後再用快捷鍵存成 WAV。

## 開始使用

從 [最新 Release](https://github.com/cacich/EchoReplay/releases/latest) 下載 `EchoReplay-Setup-x64.exe`，雙擊完成安裝後從開始功能表開啟。或下載 `EchoReplay-portable-win-x64.zip`，解壓縮整個資料夾後執行 `EchoReplay.exe`。兩者均包含 .NET 執行環境，一般情況不需要系統管理員權限。

安裝版預設位置是 `%LOCALAPPDATA%\Programs\EchoReplay`。不要下載 Release 中的 Source code，除非要自行修改或編譯。

1. 預設開啟即開始錄音，保留最近 **5 分鐘**。
2. 在「設定」選擇 Discord／遊戲實際使用的播放裝置，以及自己的麥克風。
3. 確認兩個音量條在有聲音時會動。
4. 按 **Ctrl + Alt + F9** 儲存按鍵當下之前的音訊。
5. 按 **Ctrl + Alt + F10** 顯示／隱藏視窗。

尚未累積滿指定時間時，會保存目前已累積的長度。快捷鍵可在設定欄位中直接按下新組合鍵，再按「套用設定」。若組合鍵已被其他程式占用，會顯示錯誤，並嘗試恢復原快捷鍵。

## 背景與開機執行

- 按視窗的 X、最小化或「縮到系統匣」，程式會繼續錄音。
- 雙擊右下角系統匣圖示，或按介面快捷鍵，即可叫回視窗。Windows 可能把圖示收在 `^` 中。
- 系統匣右鍵可儲存音訊、暫停／開始錄音、開啟資料夾及**結束程式**。
- 在設定勾選「登入 Windows 時自動執行」並套用，即可於登入後在系統匣啟動；搭配「啟動程式後自動開始錄音」即可自動錄音。
- 開機啟動預設關閉。啟用後會在目前使用者的 Windows Run 登錄機碼建立 `EchoReplay` 項目；取消勾選並套用會移除。
- 若移動程式位置，從新位置開啟，再按一次「套用設定」，更新開機啟動路徑。
- 重複開啟程式會喚出既有視窗，不會同時錄兩份。

## 輸出與設定

預設輸出到使用者的「音樂」資料夾下的 `EchoReplay`。可在設定中輸入完整路徑或按「瀏覽」選取資料夾。

每次儲存建立一個獨立的 `Replay_日期_時間_識別碼` 資料夾：

| 檔案 | 內容 |
| --- | --- |
| 混音.wav | 電腦聲音＋麥克風，立體聲 |
| 電腦聲音.wav | 原始電腦聲音，立體聲；勾選分軌時輸出 |
| 麥克風.wav | 原始麥克風，單聲道；啟用麥克風及分軌時輸出 |
| 錄音資訊.json | 時長、來源狀態及擷取中斷計數 |

全部音檔為 48 kHz / 16-bit PCM WAV。混音音量可分別調整為 0–200%，接近滿幅時使用柔性限制，減少聲音重疊時的爆音；分軌維持原始音量。可直接「試聽最新混音」或「查看音檔」。試聽使用 Windows 預設播放器，播放聲音也可能被錄入下一個片段。

設定保存在 `%LOCALAPPDATA%\EchoReplay\settings.json`。設定套用前會檢查輸出位置可否寫入。修改保留時間、來源裝置或麥克風開關後套用，會重新開始累積錄音；輸出位置、快捷鍵、音量與啟動設定不會清除緩衝。

## 使用上的邊界

- **必須先讓程式執行並錄音，才能保存過去的聲音。** 暫存音訊只在記憶體中；結束程式、斷電或重新開始錄音都會失去未儲存的內容。
- 「暫停」後仍可存下原有緩衝；「開始新的錄音」會清除原有緩衝。
- 第一版擷取**一個播放裝置**及**一個麥克風**。若 Discord 和遊戲播放到不同裝置，請先將它們改成同一個輸出裝置。
- 「跟隨 Windows 預設」使用 Windows 的預設多媒體裝置。Discord 若指定了其他裝置，請在此工具明確選擇相同裝置。
- 麥克風是直接從 Windows 裝置擷取，**Discord 內的靜音、按鍵發話、降噪或音量設定不會控制這份錄音**。可在本工具關閉麥克風錄製，或使用硬體靜音。
- 來源斷線會提示並每 2 秒重試；預設裝置切換也會偵測並重新連接。中斷或睡眠期間的聲音無法補回。固定指定的裝置離線時，會等候該裝置恢復。
- 音量條安靜可能只是當時沒有聲音。請播放一段聲音並說話來檢查；來源未連線的警示與單純安靜不同。
- 麥克風需允許 Windows 的「讓桌面應用程式存取您的麥克風」。本機若沒有可用裝置，會顯示中斷並等待連線。
- 音訊由 Windows WASAPI 擷取，不依賴 NVIDIA 錄影元件。特殊獨占模式或受保護音訊可能無法擷取。
- 第一版沒有內建裁切、MP3 匯出或 Discord／遊戲各自分軌。
- 5 分鐘雙來源的音訊緩衝約 87 MB，10 分鐘約 173 MB；存檔時會暫時複製緩衝，因此記憶體使用會增加。混音＋兩份分軌的 5 分鐘音檔約 144 MB。

開發、打包與診斷指令請見 [製作說明](DEVELOPMENT.md)；已驗證的範圍請見 [驗證紀錄](../VALIDATION.md)。

## 移除

先保存需要的音訊，再由系統匣結束程式。

- **安裝版：** 從 Windows「已安裝的應用程式」移除 EchoReplay。會移除程式、捷徑與指向該安裝位置的開機啟動項目，保留錄音與使用者設定。
- **免安裝版：** 先取消「登入 Windows 時自動執行」並套用，結束程式後再刪除程式資料夾。

升級安裝版時，先結束程式，再執行新版安裝檔；設定與錄音會保留。
